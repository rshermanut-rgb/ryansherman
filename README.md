# Ryan Sherman — Portfolio

A personal portfolio of professional, academic, and creative work.

## Publishing

This is a static website, ready for GitHub Pages. Publish the main branch from the repository root. No build step or package installation is required.

## Updating

Edit `content.js` for the portfolio content, then run `node tools/build.cjs` to regenerate the HTML pages. Preview with a local static web server.

Images, publications, and credited third-party materials retain their respective rights.
